# Parameters and Calibration Assets

This page is the canonical reference for parameter files under
`topeft/params/`.

## Scope

- Runtime parameter payloads and calibration-side inputs used by processors and
  helpers.
- External recommendation pointers that historically lived in
  `topeft/params/README.md`.

## B-tag working points

- CMS recommendation reference (historical pointer used by this repo):
  <https://twiki.cern.ch/twiki/bin/viewauth/CMS/BtagRecommendation>

## Notes

- The Twiki and local payloads can evolve independently; validate year/era
  compatibility before updating analysis defaults.
- For the full documentation map, see [docs/index.md](../index.md).
